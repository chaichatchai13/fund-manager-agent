ThetaFlow — Settings Page

This page shows the SMS opt-in section of the ThetaFlow application settings. The full settings page is accessible after login at theta-flows.com.

📱 SMS Trading Alerts OPTIONAL

Receive SMS alerts for price movements, position updates, and trade confirmations. Reply YES/NO to act on alerts directly from your phone.

✓ You can use ThetaFlow without SMS alerts — this consent is completely optional.

Note for reviewers: ThetaFlow is a single-user private trading application. The sole user is the application owner. The SMS consent checkbox above is unchecked by default. The user may save settings and use the full application without checking this box. Checking this box is the only way SMS alerts are enabled.
